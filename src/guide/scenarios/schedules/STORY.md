# guide-schedules

Click path (a real user, in order):
1. Scheduled tasks page — the list of existing schedules.
2. Click "Create with Agent" → the agent panel slides open, setup prompt sent.
3. The agent explains and asks three questions in a widget card: task,
   frequency, destination — click Performance digest / Every week / Email,
   then Submit.
4. The agent checks schedules and creates "Weekly performance digest" —
   the new row appears at the top of the list.
5. Click the row's dots menu → Edit settings → the edit dialog opens.
6. Add a second email recipient, click Save.
7. Click the created schedule → detail page with run history.
8. Click "Run now" → a run appears as Running.
9. Click a finished run → its chat opens: tools, digest answer, metrics.

Hook: hand the agent a job once and it runs on your schedule forever.
Wow: three clicks in a widget become a living weekly digest with its own
chat, email delivery and run history.
Voice: plain language — a scheduled task is "a job you hand the agent once";
no "cron", no "tools" jargon in VO.
Type: guide (src/guide), wide 1920x1080, VO eleven_v3.
