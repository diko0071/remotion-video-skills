# guide-brand

Hook: your agent writes like YOU — but only if it knows who you are.
Setup: Brand page, Identity tab — what you sell + tone of voice; subtitle is the whole point: agents read this on EVERY turn.
Work: tab Visual (colors/fonts — creatives come out in your palette) → tab Context → the underrated part: Agent notes. Click edit → type real rules ("B2B only, never consumer tactics, always cite sources") → Save → the card fills.
Teach: writing style prefs + real ad creative examples — give it examples, it copies the style.
Close: fill it once — every article, creative and reply across the whole platform sounds like your company.

Clicks: tab Visual → tab Context → edit notes (dialog, typing) → Save → close.
