# guide-reports — Reports: ask, and it's built

Hook: reports are made in chat — type what you need and send.
Work: the agent works your real accounts; it even opens your live store in a
browser panel next to the chat and walks the pages. Then the report opens in
the same panel — a full deck, scrolled through: score, movers, fixes. Ask
again and the same numbers become a live dashboard, always current.
Then the home of it all: the Reports list — decks and dashboards with
status — open the August review right from there and scroll the real thing.
Close: you ask, the agent builds, it's all waiting in one place.

Click path (product truth: reports module + artifact panel, seo-audit):
1. Chat composer — type "Build me a monthly performance report", send.
2. Agent tools run (skill, GSC, GA, Shopify, DataForSEO, write_report);
   browser artifact opens beside the chat (open_artifact), site scrolls.
3. Artifact swaps to the deck (write_report result), deck scrolls.
4. Composer again — "Now make it a live dashboard", send; dashboard artifact.
5. Rail → Reports: the list page (statuses: completed / in progress / failed).
6. Click "Ember & Oak — August performance review" → report detail, scroll.
