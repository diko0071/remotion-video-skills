# guide-publishing

Sources: help.get-ryze.ai/seo/programmatic.md + seo-audit modules
(programmatic-articles, seo/settings publishing, integrations). ~3.5 min.

Click path:
1. Integrations page — connect the store (Shopify card: Connect -> Connected).
2. Content Plan (list) — KPIs, tabs, statuses explained (Planned / Drafted /
   Published / Failed); ~5 a day schedule.
3. Open a drafted article -> editor: title, body, Details (slug, meta,
   scheduled date), featured image (Regenerate), Article score 92/100.
4. Ask AI to change it: "Improve This Article" -> agent panel opens with the
   real improve prompt; close panel.
5. Save -> back to list -> Publish now on the drafted row -> status flips to
   Published.
6. Settings -> Publishing: mode Manual -> Auto (segmented control), "Publish
   to" select (change provider), Override blog URL mentioned.
7. Back to list -> row menu (...) -> Republish -> dialog: platform select,
   "Remove from {platform}" checkbox -> Republish.
8. Calendar view one beat (articles by day, ~5/day) — optional if timing
   allows.
9. Close + lockup.

Wow: the drafted article goes live in one click, and auto-publish makes the
whole plan ship itself (~5 a day).
Voice: plain language. A draft is "an article written and waiting for you".
Auto-publish: "each day Ryze publishes every article whose date has arrived"
(help center wording).
