# guide-technical-audit

Hook: your site has problems you can't see. Google and ChatGPT see every one.
Setup: Technical Audit page — health 62/100 gauge + three rings (Page Speed, LLM Optimization, SEO Optimization); what each one means in plain words.
Work: issues table — site-wide checks open (llms.txt missing, AI crawler blocked, schema); click a page row → expands into its issues with severity + plain "how to fix" lines, passed checks struck through.
Wow: Fix with agent → panel: agent plans the fixes and applies them through the CMS itself.
Close: Run Scan again → health 62 → 84, rings turn green — scan, approve, done; the site stays readable for Google AND ChatGPT.

Clicks: open page (nav from rail assumed) → row expand (site-wide already open) → click page row 2 → expand → Fix with agent → panel works → close panel → Run Scan → scores rise → close.
