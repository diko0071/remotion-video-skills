# guide-templates

Click path (a real user, in order):
1. Templates page — browse the library, hover two cards.
2. Click the "Organic Traffic Overview" dashboard card → preview dialog.
3. Click "Use template" → a live dashboard report opens in Reports.
4. Click "Templates" in the rail (real navigation — different section).
5. Click the "Monthly Client Report" deck card → preview dialog.
6. Click "Build with agent" → the agent panel opens with the deck prompt,
   pulls Google Ads / Meta / GA4, writes the deck.
7. Click the report link → the deck opens in Reports, slides cascade, scroll.
8. Close on the templates library.

Hook: you never start from a blank page — the library already knows what to ask.
Wow: one click turns a template into a live dashboard; one prompt becomes a
10-slide client deck from real numbers.
Voice: plain language — no "tools", no "prompts" jargon in VO; a template is
"a ready-made job".
Type: guide (src/guide), wide 1920x1080, VO eleven_v3.
