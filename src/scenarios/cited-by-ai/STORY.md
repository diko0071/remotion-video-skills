# cited-by-ai

Voiced promo (InDrive beat language + creative-library VO pipeline).

Hook: ChatGPT full-screen, the user types "best craft chocolate brands?" —
then bam: it snaps to the top-left quadrant and Claude, Perplexity, Gemini
assemble a 2x2 grid, same question typing in each. All four answers cite...
someone else (competitor names get the marker).
Turn: "So we built an agent that fixes it." — our composer.
Work-on-screen: the cursor drag-and-drops three cards into the composer —
your website, the questions chip (pulled from the hook), your brand guide —
send; the agent writes 4 articles that stack up, then fly onto the real
ContentPlanCalendarPage until a month is full (articles, PR, backlinks).
Wow: the calendar machine-gun fill.
Close: "Be the answer in" logo beat (reuse) + lockup.

Scene budget (30fps, VO-driven): grid ~10s, agent+drag ~9s, write ~5s,
calendar ~6s, tail ~8s. Target ~40s.
